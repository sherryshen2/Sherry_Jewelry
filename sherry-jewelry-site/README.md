# Sherry Jewelry

根据《Sherry Jewelry 产品需求文档 PRD v1.0》制作的沉浸式珠宝网页。部署内容全部位于 `dist/`，无需构建、数据库或第三方运行服务。

## 查看与运行

另附 `Sherry Jewelry 离线网页.html` 单文件导出，模型、照片、字体和脚本均打包在文件内。可用本机浏览器打开；Codex 内置浏览器不允许 file 协议，因此本次交互验收针对 HTTP 运行的标准版本，单文件版仅完成脚本语法检查。

```sh
python3 tooling/preview-server.py --port 4173
```

打开终端显示的本地地址，或双击 `启动网页.command`。标准版 `dist/index.html` 需要通过本地 HTTP 服务加载模型和配置；另附的单文件离线网页可独立打开。

## 已实现

- 与主展台一致的米色首页、统一 Cormorant Garamond 字体、透明背景店面、同步浅倒影、浮动和有限角度观察。
- Explore 和店面两种入口；独立主展台，保留 v03 暖光、镜面及四个定位节点。
- 四件商品的悬浮实拍、轻微放大、右上角 The collection 高清实拍列表；手机底部缩略图支持先预览、再打开。
- 从展台位置进入商品查看层；陈列版与详情版的短交叉过渡；金色粒子、到达后的完整一圈旋转；用户可以随时接管。
- 旋转和上下翻看、滚轮与双指缩放、0.75–2.5 倍范围、复位；J001 完整项链与吊坠近景。
- 指定实拍与 3D 切换；四条完整 Shopee 外链；桌面新标签页、手机当前标签页及返回恢复。
- Esc、背景轻点、关闭按钮、弹层焦点循环、返回焦点、浏览器前进后退。
- 系统减少动态效果分支、图片模式、模型与图片失败重试、过期请求隔离、最多四款详情模型缓存。

## 更新商品与素材

编辑 `dist/data/products.json`。ID 固定 J001–J004，各页面共享这份配置。`photoUrl` 与 `thumbnailUrl` 是指定照片的网页派生图；不要根据文件顺序重新映射。`buyUrl` 必须粘贴商品表 Link 的完整值，保留查询参数。`defaultRotation` 为 xyzw 四元数；`fitPadding`、`minZoom`、`maxZoom` 控制单款取景。`anchorName` 必须与主展台 GLB 中的定位节点一致。

编辑 `dist/data/settings.json` 可更新品牌记录、场景模型、镜头构图和灯光预设记录。动画时间记录与 `app.js` 中的时间轴保持同步。`dist/data/placement.json` 保留原始主展台位置与辅助命中配置。正式陈列模型直接挂到定位节点下，使用局部单位变换；不要再次应用定位节点的位置。

`dist/engines.js` 负责 Three.js 场景、材质、镜面和模型操作；`dist/app.js` 负责页面状态、动画、键盘、触控与购买导航；`dist/style.css` 负责桌面、手机、横屏和减少动态效果样式。模型使用 Meshopt 压缩与 WebP 纹理；解码器及字体均随站点本地提供。

## 资源基线

首页：Boutique/v06-soft-front。主展台：MainDisplay/v03-light-metal-reflection。独立详情：J001 v02、J002 v02、J003 v06、J004 v03。对应源文件保留在上一级原素材目录中。

照片为用户指定的 J001/正面.jpeg、J002/细节.jpeg、J003/内圈细节.jpeg、J004/侧面.jpeg 的等比例 WebP 派生图。未添加价格、库存或未经确认的销售规格。

`asset-sizes.json` 记录压缩前后体积；`asset-manifest.json` 记录交付文件 SHA-256。`tooling/optimize.mjs` 是此次优化工具记录：它会改写 assets 中的 GLB，再次使用前应先放入原始未压缩副本。精细源文件不在网页发布包内。

## 验证与边界

详见 `QA.md` 与 `qa/` 的实际截图和测试结果。已验证桌面与 360 像素窄屏，但窄屏模拟不能代替 iPhone、Android 和微信真机验收。未宣称达到尚未实测的帧率或限速网络目标。

四条购买链接与 PRD 的完整快照逐字核对一致。Shopee 目标页面未能由检索工具访问；实际 SKU、库存和目标平台登录状态仍需在正常购物环境核对。

按用户要求仅保留本地网页与源码，不上传或发布网站。
